# 受付ご案内タブレット（デモ）

受付に職員がいないときに、タブレットで案内を表示するウェブアプリです。「スタッフを呼ぶ」を押すと、離れた場所にいるスタッフのスマホやPCに通知が届きます。

- `index.html` … 受付タブレット用
- `staff.html` … スタッフ用（PCで呼び出しを受ける画面＋スマホの設定方法）
- `config.js` … クリニック名・通知チャンネル名（topic）・メニューの設定
- `style.css` … 見た目

## GitHub Pages で公開する

1. GitHub で新しいリポジトリを作る（例：`clinic-kiosk`）
2. このフォルダのファイルを全部アップロード（「Add file」→「Upload files」）
3. 「Settings」→「Pages」→ Branch を `main` / `(root)` にして Save
4. 数分後に次のURLで開けます
   - 受付：`https://<ユーザー名>.github.io/clinic-kiosk/`
   - スタッフ：`https://<ユーザー名>.github.io/clinic-kiosk/staff.html`

## 呼び出しのしくみ

通知には無料のプッシュ通知サービス [ntfy](https://ntfy.sh) を使います。

1. 患者さんが「スタッフを呼ぶ」を押す
2. 受付タブレットが ntfy に「受付から呼び出しです」を送る
3. ntfy アプリを入れたスタッフのスマホ、または `staff.html` を開いているPCに通知が届く
4. 誰か1人が「向かいます」を押すと、受付の画面に「スタッフが向かっています」と表示され、ほかのスタッフの通知は自動で消える（Android・PC。iPhoneは通知が残ることがあります）

同じトピックを登録すれば、何台でも同時に受け取れます。

### スタッフのスマホの設定

1. App Store / Google Play で「ntfy」をインストール
2. 「＋」から `config.js` の `topic` と同じ名前を登録
3. 通知を許可（Androidは「緊急」優先度の通知が大きな音で鳴ります）

### スタッフのPCの設定

`staff.html` を開いて「待ち受けをはじめる」を押し、開いたままにしておきます。

## 設定（config.js）

- `topic` … 通知のチャンネル名。**名前を知っている人は誰でも通知を受け取れるし送れる**ので、推測されにくい英数字にしてください。リポジトリを公開（Public）にすると誰でも見られるので、気になる場合はリポジトリを Private にするか、定期的に名前を変えてください。
- `menu` … メニュー。MRI の金属類一覧は `list` で変更できます。一覧はよくある例なので、院内の検査技師の指示に合わせて調整してください。

## iPad の画面から設定を変える

受付画面のクリニック名を **3秒長押し** すると、職員用の設定画面が開きます（暗証番号を設定した場合は入力が必要）。

- クリニック名、呼び出し場所、通知のチャンネル名、戻るまでの秒数、暗証番号
- メニューの追加・削除・並べ替え、ボタンの文字、手順、金属類などの一覧、注意書き

ここでの変更は **その iPad のブラウザだけ** に保存されます。全端末に反映したいときは、設定画面の一番下「設定を書き出す」の内容を `config.js` に貼り付けて GitHub に保存してください。「初期設定に戻す」で `config.js` の内容に戻ります。

## 全画面で表示する

- **Safari で開く場合**：待機画面を最初にタップしたときに、自動で全画面になります（設定画面でオン・オフできます）。左上の「×」や画面の端からのスワイプで解除されることがあるので、その場合はもう一度待機画面をタップしてください。ページを再読み込みすると、全画面は解除されます。
- **ホーム画面に追加する場合（おすすめ）**：Safari の共有ボタン →「ホーム画面に追加」→「Web アプリとして開く」をオンにして追加すると、アドレスバーのない全画面で開きます。解除されることもありません。

## 読み上げの声を自然にする

読み上げは iPad に入っている声を使います。設定画面の「読み上げの声」で、声の種類・速さ・高さを選んで試聴できます。

より自然な声にするには、iPad に高品質な声を追加してください。
「設定」→「アクセシビリティ」→「読み上げコンテンツ」→「声」→「日本語」→ 声の名前に「（拡張）」や「（Premium）」が付いたものをダウンロード。
追加したあと受付ページを開き直すと、設定画面の一覧に出てきます（iPadOS のバージョンによっては、ブラウザから使えない声もあります）。

## タブレットの設定のおすすめ

- 画面の自動ロック（スリープ）をオフ
- iPad：アクセスガイド／Android：アプリ固定 で、他のアプリを開けないようにする
- Chrome の「ホーム画面に追加」で、アプリのように全画面で開ける

## 注意

- 通知の本文には患者さんの名前などの個人情報を入れていません（「受付から呼び出しです」のみ）。
- ntfy.sh の無料サーバーは稼働が保証されていません。本格運用では、ntfy の有料プランや自前のサーバーも検討してください。
